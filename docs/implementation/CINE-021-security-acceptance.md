## Limits and operation

- Per 60-second window, the network quotas are 20 create, 30 join, 60 vote and 24 token requests. Signed guests have 60 vote and 12 token requests per room. Both create paths share a quota, as do both join paths and the vote aliases. A denied request returns `429`, `Retry-After`, and `no-store`.
- Vercel supplies the network identity at ingress. IPv6 accounts for a /64. Requests without a trusted address share a network bucket. SQLite uses an in-process counter for offline development and tests. PostgreSQL is required for the shared production authority. Expired counters stop enforcing the old window immediately and are pruned in bounded batches as traffic continues.
- Supabase session-mode endpoints on port 5432 default to two connections per application pool. `CINEMATCH_PG_POOL_MAX` accepts 1–10, and the outbox worker uses at most two. The hosted 15-session limit applies to the combined deployment. Budget all app processes, live route pools, the worker, and administrative sessions before release. Pooler capacity rejection returns `503` with `Retry-After: 3`; quota rejection remains `429`.
- Apply migration 006 before starting the new app and outbox worker. Keep `cinematch_private` outside exposed API schemas. Self-hosted deployments terminating TLS at a proxy use `CINEMATCH_APP_ORIGIN` for the public browser origin. If rolling back 006, revert the application and worker binaries first. The down migration has been designed to preserve room data and restores the pre-006 policy definitions.
- Alert on `CINEMATCH_REALTIME_AUTH` and verify that the configured server key matches the project and broadcast permissions. Check provider connectivity and the age of the oldest eligible outbox event on `CINEMATCH_REALTIME_UNAVAILABLE`. Inspect quarantined event counts on `CINEMATCH_REALTIME_REJECTED`. Transient retries are capped at 60 seconds between attempts. Authorization retries wait at least 60 seconds and at most 15 minutes between attempts. A rejected oversized event is quarantined after three permanent failures. Outbox hints remain best-effort and room snapshots remain authoritative.
- CINE-018 recorded a partial credential fragment in a private tool trace. Published scans and the owner's report about access to the trace do not establish who could access private records. Review trace access with the owner or provider if the scope changes. A fragment with no verified outside access does not justify rotation by itself. Do not include live keys, cookie values, JWTs or raw transport traces in evidence.
- Real hosted JWT signature, expiry, subscription, and reconnect behavior require the managed Realtime service after migration. Local SQL role checks isolate the policy decision. CINE-019 owns client reconnect and concurrency behavior.
